# Plans

Active and completed feature designs and implementation plans.

The cross-cutting delivery roadmap is tracked in
[`roadmap.md`](roadmap.md). Deferred technical debt remains tracked in
[`technical-debt.md`](technical-debt.md).

## Lifecycle

1. Create a feature design in `active/YYYY-MM-DD-<feature>-design.md` (see [../templates/feature-design-template.md](../templates/feature-design-template.md)).
2. Once approved and shipped, move it to `completed/`.
3. Record deferred debt in [technical-debt.md](technical-debt.md), not in code comments alone.
