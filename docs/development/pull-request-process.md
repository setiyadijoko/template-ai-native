# Pull Request Process

**Status:** Template policy.

1. Open an issue for substantial changes first.
2. Branch from `main`; keep the PR focused.
3. Complete the PR template (`.github/pull_request_template.md`) including the AI discipline checklist.
4. Required checks must pass; at least one reviewer; CODEOWNERS for sensitive paths.
5. Squash-merge with a Conventional Commit title.
